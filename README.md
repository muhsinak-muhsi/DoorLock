# Password-Based Door Lock System Using Arduino

## Project Overview
This project implements a password-based electronic door lock system using Arduino. Users can enter a password through a 4x4 keypad to control the door locking and unlocking mechanism.

## Components Used
- Arduino Uno
- 4x4 Matrix Keypad
- Servo Motor
- 16x2 I2C LCD Display
- Buzzer
- Connecting Wires

## Working Principle
1. The LCD displays a password entry message.
2. The user enters the password using the keypad.
3. Arduino verifies the entered password.
4. If the password is correct, the servo motor controls the door lock mechanism.
5. If the password is incorrect, the buzzer provides an alert.
6. The LCD displays the password verification status.

## Software and Libraries
- Arduino IDE
- Embedded C / Arduino C++
- Servo Library
- Keypad Library
- LiquidCrystal_I2C Library

## Key Features
- Password-based access control
- Automatic password verification
- Servo motor-based locking mechanism
- LCD status display
- Buzzer alert for incorrect passwords

## Applications
- Electronic door security
- Access control systems
- Basic home automation projects
